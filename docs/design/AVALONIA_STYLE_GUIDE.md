# Avalonia 界面规范落实记录

依据：用户提供的十条 UI 规范；[desktop-agent-ui](https://github.com/Ludi-Herry/desktop-agent-ui)。用户明确的无边框要求优先于参考仓库的半像素边框建议。继续使用 Avalonia Fluent，不引入 WebView 或第二套组件库。

## 当前实现

浅色层次：画布 #f5f5f3、阅读区 #fcfcfb、侧栏与输入区 #efefed。正文 #292b29，次级文本 #686c68，主操作 #27634a。相邻底色以约 1%–3% 灰度差区分；状态和文字仍保持可辨识对比。

字体使用 Microsoft YaHei UI / Segoe UI；字号收敛为 12、14、18、26。主操作仍为“继续工作”。不新增仪表盘、装饰卡片或流程步骤。

| 用户规范 | 原生实现 / 当前边界 |
| --- | --- |
| 微明度分层、去边框 | 移除应用面板分隔线和输入描边；保留系统窗口控制区 |
| 输入焦点双环阴影 | Fluent TextBox 原模板上覆盖两层 inset BoxShadow，去焦点下划线；保留原生文本选择和输入法 |
| 暗色字重减 40 | 当前只支持浅色；暗色实现时需选择支持数值字重的字体并实测，不能把静态字体 360 当成已生效 |
| 单字模糊流式效果 | 当前没有流式生成。未来按 90ms、6px、30ms、指定曲线实现，并支持减弱动态效果 |
| 行内图标对齐 | 当前无行内图标组件；复制提示为完整短标签。未来原生图标按字体基线/光学中心对齐，不写无效 CSS |
| 数字等宽 | 列表元数据与状态文本使用 FontFeatures="tnum"；效果依赖所选字体支持 |
| Grid 折叠过渡 | CSS 0fr/1fr 不适用于 Avalonia；保留原生 Expander，本轮没有新增高度测量或声称实现此动效 |
| text-wrap:pretty | Avalonia 无同名属性；保留原生中文换行，约束阅读栏宽度；没有声称实现孤字优化算法 |
| 拖拽/对勾弹簧 | 当前无拖拽和点赞；未增加弹簧库。本轮复制只做淡出，不声称实现 380/18 弹簧 |
| 复制反馈自熄 | 三个复制入口只在剪贴板写入成功后显示对勾，2.5s 后开始 160ms 淡出并恢复；重复点击重置计时，关窗停止计时器 |

侧栏允许滚动，长正文输入设最大高度，保留键盘导航。错误提示不自动消失。按钮焦点提示保留；TextBox 使用自定义双环表示焦点。

## 截图反馈后的结构修订

- 默认只展示搜索、最近记忆与继续工作；点击记一条/记录才显示编辑页。
- 列表展示标题和摘要，技术类型与版本移入详情。
- 无项目时隐藏空项目标题和列表，侧栏只保留添加入口。
- 续接背景放在主列表上方；编辑页头部返回、底部保存固定，正文独立滚动。
- 来源、条件、类型和历史统一折叠到补充详情；连接正常时隐藏底部技术状态和重连按钮。
- 未保存编辑返回列表后提供继续编辑；打开其他记录不会覆盖未保存内容。草稿仍只在当前窗口内存保留。
- 更新了 Fluent Expander 内部使用的边框资源，修正仅设置外层 BorderThickness 未去除标题描边的问题。
- 构建/自包含发布/客户端烟雾测试通过；真实窗口验证默认隐藏表单、打开编辑、仅标题草稿返回与恢复，验证草稿未写入数据库。
- 原生截图仍超时，未声称完成新布局的像素验收。
