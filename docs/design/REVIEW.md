环境：Node.js VM + 最小元素替身，执行原型中的实际脚本。没有浏览器、真实 DOM、剪贴板、布局、网络或 MCP。

初次结果：4通过/1失败；两次连续纠正后撤销错误恢复最初陈述。
修复：编辑会话保存前一版本的正文与依据状态；撤销恢复紧邻前一版本，同时版本号递增使既有上下文失效。
复测：5通过/0失败。

| 场景 | 核验的性质 | 结果 |
|---|---|---|
| 先生成，再自定义纠正，再生成 | 旧包禁复制，新包保留纠正与阻塞 | 状态检查通过 |
| 并发更新，旧稿重试，再重新读取 | 旧稿拒绝，重新读后允许保存 | 状态检查通过 |
| 离线编辑与恢复 | 不提交、保留草稿、恢复后保存 | 状态检查通过 |
| 连续两次纠正后撤销 | 回到前一次纠正，非最初陈述 | 修复后通过 |
| 模拟读取与采用状态 | 返回成功不升格为已采用 | 状态检查通过 |
