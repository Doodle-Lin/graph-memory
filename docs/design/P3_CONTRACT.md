# P3 批次契约：草稿抗崩溃、召回可测量、本机协议加固

状态：生效（2026-11-04）。基线：`a1bc215`（P2 完成）。本文件是本批次唯一权威契约；三份实现任务（task-16/17/18）与独立验收（task-19）都以本文件为准，冲突时以本文件为准并在执行账本记录偏差。

## 为什么是这三件事

P0/P1/P2 之后，"能装、能用、数据可托付"已经成立，但仍有三处会直接影响"实际可用"：

1. **草稿只活在内存里**：桌面已有"关窗保护"和按 scope 的草稿表，但进程一旦被杀/崩溃（不是正常关窗），未保存内容全部丢失。计划里 L2-06 明确要求"崩溃可恢复"，这是用户最容易感知的损失。
2. **召回质量没有数字**：检索策略（词条 + 中文 bigram）经过多轮修改，却没有任何可复现的评测集与基线。没有基线就无法判断"继续优化检索"是否真的变好，也无法诚实对外说明当前水平（L4-01）。
3. **本机 HTTP 接口没有资源上限**：请求行/头/正文都没有上限、没有超时、没有并发上限，`static_server.rs` 里还用 `&req[..req.find(' ')]` 直接切片。本机其他进程（或误连的脚本）可以轻易让服务分配无界内存或阻塞线程（L5-02）。服务只监听 127.0.0.1，但这不等于可以不做资源边界。

## 通用纪律（三个实现任务都适用）

- **写作用域互不重叠**：task-16 只碰 `desktop/GraphMemory.Desktop/**` 与 Editor 套件；task-17 只新增 `tests/eval/**` 与 `docs/design/RECALL_BASELINE.md`（只读产品代码）；task-18 只碰 `src-tauri/src/static_server.rs`（可拆子模块）与 `tests/test_headless_service.py`。
- **cargo 构建互斥**：任何时刻只允许一个 owner 跑 `cargo build/test`（target 目录共享）。task-17 使用已构建的 debug 二进制，不自行编译；task-18 编译前先确认没有其他成员正在编译。
- **中文与编码**：`.ps1` 必须 UTF-8 BOM；断言中文请显式按 UTF-8 读取原始字节（不要依赖 `Invoke-RestMethod` 默认解码，PS 5.1 会按 Latin-1 解）；`Start-Process -ArgumentList` 不自动为含空格路径加引号。
- **不许静默失败**：任何降级/失败都要有用户可见或日志可见的说明，不得把"没报错"当成"成功"。
- **测试只增不改**：既有断言不得删除或放宽；新增断言必须能被第三方按同一命令复现。

## task-16：草稿持久化与崩溃恢复（L2-06）

语义：

- 草稿落到**工作库之外**：默认 `%LOCALAPPDATA%\GraphMemory\desktop-drafts\`，可用环境变量 `GM_DRAFT_DIR` 覆盖（测试与 CI 用）。**绝不在 `--data-dir` 内写任何草稿文件**（否则会污染备份/校验的输入集合）。
- 文件按"工作库 + 视图"分片：键至少包含 `data_dir`（用规范化路径的稳定哈希）与 scope 键（项目 id 或 `personal`）；每条草稿记录 `memory_id`、基线 `version`、`origin`、`kind`、`evidence_type`、标题、正文、来源、适用条件、以及"是否新建"。
- 写入必须是**原子**的（临时文件 + 替换/改名），任意时刻断电只会丢最后一次保存，不会留下半截 JSON。
- 读取时文件缺失或损坏（非 JSON、截断、字段类型不对）→ 视为空草稿集，并在界面上给出一句可读说明；**不得**因此崩溃或阻塞启动。
- 恢复时机：启动进入主页/切换 scope/打开编辑器时，若该 scope 有草稿，编辑器显示草稿内容并明确提示"这是上次未保存的草稿"。
- **版本过期必须重读**：草稿记录基线版本；若该记录的当前版本 > 基线版本，界面必须提示"记录已被其他会话更新，草稿需重新核对"，并保留既有 409 处理路径（保存失败保留草稿、可加载历史、放弃后载入最新版本）。禁止静默用草稿覆盖他人更新。
- 清除：现有"放弃草稿"必须同时删除持久化文件中的对应条目；工作库变化导致的孤儿草稿（`data_dir` 不再匹配）不得被加载，也不得无限增长（实现需给出确定性的清理规则并在文档写清）。
- 草稿**不进入记忆库**：不经 HTTP/MCP 写入，不参与检索、上下文、导出。

验收（Editor 套件至少新增 15 条断言，全部可复现）：

1. 保存草稿 → 新进程实例读取同一 `GM_DRAFT_DIR` → 标题/正文/来源/条件/kind/evidence 完全一致；
2. 未保存的新记录草稿（无 `memory_id`）同样可恢复；
3. 基线版本过期时提示文案出现，且保存仍走 `expected_version` 冲突路径（fake 服务返回 409 时草稿不被清空）；
4. "放弃草稿"后持久化文件中该条目消失；
5. 损坏文件（写半截 JSON、写非 JSON 文本、写空文件）→ 启动不崩溃、返回空集、有说明；
6. 断言草稿目录下确有文件，且 `--data-dir` 目录内**没有**新增任何草稿文件；
7. 不同 `data_dir` 的草稿互不可见（隔离）。

## task-17：中文检索/续接评测集与基线（L4-01）

语义：

- 新增 `tests/eval/`：数据集 + 播种夹具 + 基线运行器（只用 Python 标准库），**不改产品代码**。
- 数据集 ≥ 40 条，每条含：`id`、`query`、`scope`（project/personal）、`project`、`expected_ids`（可为空 = 无正确答案）、`category`。类别必须覆盖：同义改写、项目冲突（同一问题在两个项目里有不同答案，必须只召回本项目）、中文长句（≥25 字自然问句）、过期/已撤回、无结果（不得误召回）。
- 播种夹具含已知 id/版本的中文记录，包含：阻塞/下一步/决策三类、个人经验、被撤回记录、以及两个项目里语义相近但内容不同的记录。写入必须用真实 v1 HTTP 接口（含 `event_id`，保证可导出）。
- 运行器行为：随机端口启动**冻结的 debug 服务**（不自行编译），在全新临时目录播种，跑完所有查询，计算并写出：
  - `Recall@5`（有答案的查询中，答案进入前 5 的比例）
  - `MRR`
  - 跨项目污染率（项目中查询命中其他项目记录的比例，必须为 0 才算通过）
  - 无答案误召回率（无结果类查询返回非空的比例）
  - 已撤回记录泄漏数（默认查询命中已撤回记录的数量，必须为 0）
- 产物：`artifacts/eval/run-<时间戳>/report.json`（逐条查询的 query/期望/实际/名次）、`report.md`（分类别汇总 + **最差的 10 条**）、以及 `docs/design/RECALL_BASELINE.md`（只写实测数字、硬件/时间/二进制路径与 SHA256；不许写未测的数字或"应该会更好"）。
- 允许基线难看：这是测量，不是营销。若某类别 0 命中，如实记录并给出最小复现。

验收：脚本连跑两次结果一致（同夹具下 Recall@5/MRR 完全相同）；`report.json` 可机读；`docs/design/RECALL_BASELINE.md` 的每个数字都能在 `report.json` 里找到来源；跨项目污染率 = 0、撤回泄漏 = 0。

## task-18：本机协议加固（L5-02 最小集）

语义（默认值可在实现中微调，但必须写进文档并测试）：

- 请求行 + 头部总量 ≤ **32 KiB** → `431`；正文 ≤ **1 MiB** → `413`。超限时必须**边读边判**，不得先 `read_to_end` 再检查。
- 单连接读写超时 **15s** → `408`；同时处理的连接数 ≤ **64**，超出 → `503`（不排队、不阻塞主循环）。
- `/api/v1/*` 只接受 `GET`/`POST`（以及既有已支持的方法），其他方法 → `405`，响应带 `Allow` 头。
- 请求行/头部畸形（没有空格、无路径、非法字节、非 UTF-8 路径）→ `400` 且**不得 panic**；现存的 `&req[..req.find(' ')]` 直接切片必须消除。
- 错误响应统一 `application/json; charset=utf-8`（保持 P2 修复），且与大响应一样有 `Content-Length`，不得只发头。
- 加固不得破坏既有行为：所有既有端点、既有 Rust 用例、两个 Python 套件、桌面 smoke 必须全绿；超时值不得短到让正在服务的请求失败（备份/导出走的是另一个进程，不受影响）。
- 日志：拒绝请求时记录原因与计数（不含正文），便于用户自查。

验收：Rust 侧新增用例覆盖 413/431/405/400-garbage/并发上限；`tests/test_headless_service.py` 增加真实套接字断言（含超大 `Content-Length` 声明但少量字节的欺骗请求也要被拒）；`cargo test --no-default-features --lib` 全绿；现有两条 Python 套件与桌面 smoke 全绿。
