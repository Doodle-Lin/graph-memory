# 关键交互流程表

此表用于Avalonia交互实现与原型核对。状态名用于设计审查，正式界面使用用户语言。

| 起点/触发 | 用户看到什么 | 主动作与结果 | 失败与恢复 |
|---|---|---|---|
| 无项目/首次打开 | 简要用途、关联项目目录 | 确认目录与名称，获得稳定项目ID | 重复目录进入原项目；目录不可访问可重选 |
| 项目无记录 | 尚无可恢复内容，提供一份简短交接表单 | 保存带时间和主体的陈述，不伪装验证 | 服务不可用保存本地草稿，重连后明确提交 |
| 接入Agent | 改哪些配置、配置/握手/调用分开 | 备份并配置，执行合成检查 | 失败恢复原配置；允许跳过，不阻塞手工交接 |
| 有项目/继续任务 | 当前范围、当前状态、阻塞、下一步、依据标签 | 选任务或项目级恢复，查看上下文 | 缺范围提示；缺证据保留陈述，不能生成假结论 |
| 核查一项结论 | 右侧显示原始依据、时间、范围、版本 | 展开来源或纠正此条ID | 来源不存在显示摘录及不可复核，不死链无解释 |
| 纠正保存 | 原内容与编辑草稿 | expected_version一致才新建版本并使包过期 | 冲突显示最新内容和草稿，用户重读后再保存 |
| 连续纠正后撤销 | 即将恢复的前一版及影响范围 | 恢复前一内容/依据，创建新版本 | 有后续修改不能盲撤；进入差异核对 |
| 切换项目 | 当前项目名始终可见 | 清空旧选择，进入新项目；草稿仍归原项目 | 返回旧项目提示未提交草稿并验证版本 |
| 全局搜索结果 | 每项明确项目和适用范围 | 点击先切项目，再打开记录 | 无访问/已删除显示原因，不留旧项目标题 |
| 生成上下文 | 原文可展开、事实与陈述分区、缺口明确 | 复制或Agent读取，分别记录返回/引用/采用 | 缺必要阻塞预算则标不完整，不静默截断 |
| 来源更改/纠正发生 | 旧包“已过期”及原因 | 重新生成，旧版历史仍可查看 | 未能核查显示核查时间和不确定性 |
| 服务离线 | 只读快照及时间、恢复连接入口 | 编辑可成草稿，恢复后校验再保存 | 禁止显示当前事实已更新；不丢草稿 |
| 模型未就绪 | 浏览可用、语义搜索暂不可用 | 关键词检索或等待加载 | 失败有重试与诊断，不堵住整个应用 |
| 关闭窗口 | 首次说明后台服务是否继续 | 默认后台保留（已启用时），可重新打开 | 明确退出服务入口提示Agent暂停可用 |
| 导出/移除项目 | 展示对象范围、缓存/备份保留说明 | 导出可恢复结构；软删除有恢复入口 | 永久清除单独操作，不声称能撤回Agent已收到内容 |

## 原型忠实度清单
现有desktop-prototype.html验证了单项目纠错、上下文失效、模拟读取和异常状态。已加入首份交接表单、双项目切换、草稿隔离与证据时间/范围/版本展示；真实目录关联/Agent接入、全局搜索、导出/移除仍未覆盖；这些条目不能在设计审计里标原型完成。
原型是流程示例，不承担正式安装或迁移；技术生命周期由IMPLEMENTATION_PLAN中的M1/M4验证。
